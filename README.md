# 奶龙中学奇遇 · Nailong School Saga

一个纯前端（单个 HTML 文件）的横板平台射击小游戏：你原本是一只普通的奶龙，想要在艺术节晚会的节目上登场。
但是某个名为 **XL** 的势力憎恶你的出现，于是你化身奶蛙，打入树德中学德育处，进行奶蛙的复仇……

## 直接玩

打开 `index.html` 就能玩（图片、音频全部内嵌在这个文件里，没有任何外部依赖，离线也能跑）。

## 操作

| 操作 | 键盘 | 手机 |
|---|---|---|
| 移动 | `A` / `D` 或 `←` / `→` | 左手十字键左右 |
| 跳跃 / 二段跳 / 蹬墙 | `W` / `空格`（长按跳更高） | 左手十字键「跳」 |
| 从平台落下 | `S` / `↓` | 左手十字键「下」 |
| 瞄准 | 鼠标 | 右手摇杆 |
| 开火 | 鼠标左键 | 摇杆推出去自动开火 |
| 格挡 | 鼠标右键 / `Shift` | 右下「盾」键 |
| 切换武器 | `1`–`9`、`Q` / `E`、滚轮 | 底部武器槽 |
| 进入下一层 | `Enter` | 「进入」按钮 |
| 音乐开关 / 暂停 | `B` / `Esc` | 设置里 |

## 内容

- 9 把武器（冲锋枪、加特林、RPG、喷火筒、长枪、大剑、手榴弹、燃烧弹、盾牌），随机强化 +1/+2
- 8 种敌怪（史莱姆 XL、飞行史莱姆 XL、大史莱姆 XL、大飞行史莱姆 XL、石块 XL、大石块 XL、滚木 XL、老牧师 XL）
- 每 5 层一场老牧师 Boss 战，第二次起进入「XL 红温了！」二阶段
- 每层难度 +5%，武器/敌怪/数值都能在「设定编辑器」里实时改
- 主界面「图鉴」可以查所有武器与敌怪的数值和攻击逻辑

## 部署到 GitHub Pages

1. 新建一个仓库，把本目录的 `index.html` 和 `.nojekyll` 传到仓库根目录。
2. 仓库 **Settings → Pages → Build and deployment**：
   - Source 选 **Deploy from a branch**
   - Branch 选 `main`，目录选 **/ (root)**，保存。
3. 等 1–2 分钟，打开 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> 也可以把这两个文件放到仓库的 `docs/` 目录，第 2 步目录选 `/docs`。
